Good answers get stranded

Two models, two versions of the truth

Claude plans one thing, ChatGPT works from another, and you become the sync layer between them.

Set it up once. Use it from anywhere.

  1. Create a project

    Add the notes and files that describe what you’re working on.

  2. Connect your AIs

    Paste one MCP server entry into each tool you use. That’s the whole setup.

    {
  "mcpServers": {
    "indchat": {
      "url": "https://your-workspace.indchat.com/mcp"
    }
  }
}

  3. Work in whichever one fits

    Every model sees the same project and saves back to it, with its name on the change.

You stay in charge of what the AIs write.

Every change has an author

See which model wrote what, and when. Nothing appears in your project without a name on it.

Version history

Each save is a version. Go back to any earlier state of a file or the whole project.

Approve or revert

Review a model’s edit before it becomes the current version, or undo it after the fact.

Bring any MCP-capable tool

indchat speaks the open protocol, so it isn’t tied to one vendor’s app.
